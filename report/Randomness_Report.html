Appendix A: Method (fixed before results)

  • Merge: the 7 files were aligned by row position (328 rows each, no missing values) → data/merged/merged_7_files.csv. SHA-256 hashes of the inputs are in README.md.
  • Uniformity: Pearson χ² against the discrete uniform on [min, max] (expected count per value is 10.6–46.9, so every expected count is ≥ 5). Discrete KS (Conover 1972) with a conservative Kolmogorov p-value.
  • Independence: sample ACF at lags 1–20 with a ±1.96/√N band. Runs up-and-down test (E=(2n−1)/3, Var=(16n−29)/90, zero differences dropped). Wald–Wolfowitz runs above/below the median (ties dropped). Both use the two-sided normal approximation.
  • Entropy: plug-in Shannon entropy in bits, divided by log₂k. Binary entropy of each bit stream.
  • NIST: Python implementation of SP 800-22 Rev.1a (scripts/nist_sp800_22.py), because the official NIST STS download host was not reachable from the analysis environment. Parameters: Block Frequency M = smallest value with M≥20, M>0.01n, N<100. Longest Run M=8 (n<6272) or 128. Non-overlapping template B=000000001, N=8 (all 148 aperiodic m=9 templates also run, see Appendix C). Serial m = ⌊log₂n⌋−3. ApEn m = ⌊log₂n⌋−6. α = 0.01.
